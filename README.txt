CarCare Website — 5-page HTML/CSS/JavaScript prototype

Open index.html in your browser to start.
Navigate using the links across the top.
On the Prototype page, edit the vehicle and add maintenance records.
Your changes persist in that browser using localStorage.

For GitHub Pages: create a public repository, upload index.html, about.html,
prototype.html, marketing.html, guide.html, style.css, script.js and the assets folder.
Go to Settings > Pages > Deploy from branch > main / root, then save.
GitHub will provide the public URL after deployment.

The sample vehicle, mileage, costs and maintenance intervals are fictional demo data.
